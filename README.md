# SaveQuest
A tiny retro savings tracker built with plain HTML, CSS and JavaScript.

## Run it
- Open `index.html` in a browser, or
- Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch** (choose `main` and `/root`).

## Features
- Manual deposits with quick amounts and custom amounts
- Running ZAR savings total and coin tally (1 coin per R100 cumulative savings)
- Savings goal progress, milestone notifications, deposit history, CSV export and undo-last-deposit
- Saves data in this browser using `localStorage`; no account or backend required

## Important
The tracker stores data only in the browser/device where it is used. Clearing site data or switching browsers/devices can lose the history. Export the CSV occasionally as a backup. This is a manual tracker, not a bank integration.
